04 Skills

  • Laravel / PHP

    A widespread, well-documented framework: the software stays solid over time and any Laravel developer can work on it, with no dependence on a single person.

  • Vue / JavaScript

    Fast, clear interfaces that reduce mistakes and training time for the people who use them every day.

  • Progressive Web App

    An app you can install on phones and computers without going through the app stores: one build instead of three, instant updates for everyone.

  • Third-party integrations

    Management systems, CRMs, payments, shipping and invoicing that talk to each other: less data copied by hand, fewer mistakes.

  • AI integration

    AI features inside the software you already use, to classify documents, extract data or answer customers. Only where they genuinely save time.

  • Development with AI agents

    I work every day with Claude Code and Codex: AI agents are a permanent part of my workflow, and I always review and verify the code they produce. Shorter timelines without giving up quality.

  • Legacy system refactoring

    I tidy up ageing software one piece at a time while it keeps running: no rewrites from scratch, no downtime.

  • Legacy system maintenance

    Security updates, fixes and small improvements for the software the company works on every day, even if someone else wrote it.

  • MySQL / database

    Data organised well from the start: reliable reports, fast searches and a system that holds up as the data grows.

  • Docker / Linux servers

    Development, testing and production configured the same way: predictable releases and fewer surprises at go-live.
